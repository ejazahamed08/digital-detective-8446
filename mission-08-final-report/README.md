# Topics Explored
A list of topics covered:

1. Basic networking concepts : LAN, WAN, DNS, routers, and packets.

2. Number systems : binary, decimal, and hexadecimal conversions.

3. Command line tools for DNS lookup.

4. How web browsers and servers communicate over the internet.

# How to Run the Number Converter

1. Open your terminal.

2. Navigate into mission-06 by typing cd mission-06-numbers-data.

3. Run the script by typing python3 number_converter.py.

# What I Learned
This project helped me revise the concepts I learned in my lectures. I learned exactly what happens when you type a website URL into a browser, how DNS translates domain names to IP addresses, and how to write a Python script that converts human numbers into binary code.

Note: Each mission in this repository was documented and committed to GitHub separately.
