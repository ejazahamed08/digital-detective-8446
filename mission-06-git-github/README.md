| Git operation | What it does in your own words |
|---|---|
| Check repository status | git status : staging status |
| Stage selected changes | git add : stages files/folders |
| Create a commit | git -m commit : commits changes |
| View commit history | git log : checks commit history |

A branch is a copy of the main repo.
Pull requests is a way to merge branch contents to the main repo everyone is building on.


1. git init : initializes git in repo
2. git status : checks staging status
3. git add : stages changes
4. git commit : commits changes
5. git log : history of commits
6. git branch : creates branch
7. git switch : switches between branches and main
8. git push : pushes changes to github
9. git pull : retrieves latest repository

git commands used : git init, git add, git commit. git branch, git switch, git push, git pull, git add remote

branch helps user experiment with the repo without worrying about damaging the repo.
