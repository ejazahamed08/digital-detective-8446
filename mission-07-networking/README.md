| Concept | Explain it in your own words | Example |
| :--- | :--- | :--- |
| LAN | A network covering a small area, such as a home, lab or office. | Wifi network connecting a laptop, phone, and printer. |
| MAN | A network covering a city or large campus area. | A university campus network |
| WAN | A network covering large geographical areas. | The Internet that connects PCs globally across countries. |
| DNS | Translates a domain name into an IP address. | Typing "github.com" and having it translate to an IP address. |
| Router | Connects networks and forwards data between them. | A home router that connects your local devices to your ISP's network. |
| Protocol | A set of rules devices follow to communicate. | HTTP is used for web browsing. |
| Packet switching | Data is divided into packets that travel across a network. | Sending an image over Discord, which is broken into small data chunks, routed independently, and then reassembled on the receivers end. |
| Client-server | A client requests a service and a server provides it. | A web browser requests a web page from a web server. |

1. A connectivity test verifies that a network path exists between the device and the server.
2. A DNS lookup displays the server and address.
3. When we type a website name in a browser, it goes to the server, and DNS maps the website name to the IP address for the server to then processes the request.


1. The client opens the browser and types in a website address.

2. The computer checks DNS to translate that human-readable name into an IP address.

3. The client's router then sends the request across the internet network to find the correct destination.

4. The destination server receives and processes the request, and then sends the website files back to the client.

5. The browser puts the files together, and the webpage is the final response displayed to the user.
