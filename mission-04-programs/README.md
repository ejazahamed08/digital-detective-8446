| Point | Compiler | Interpreter |
|---|---|---|
| When translation/execution happens | Before the program runs | At runtime |
| Typical output | Machine code (or executable file) | Program execution result |
| One example | C++ | Python |
| One advantage | Faster execution speed | Easier debugging and error handling |

Compilers go through the entire code first checks for repeating blocks of code and saves it if that repeating block comes later it uses the saved copy doesnt need to execute it again thus saving execution time.
Interpreters execute line by line at runtime.
